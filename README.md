# 🌳 Thai Durian Intelligence Dashboard

แดชบอร์ดข้อมูลและระบบวิเคราะห์สถิติทุเรียนไทย รองรับการดึงข้อมูลเรียลไทม์ผ่าน Open-Meteo API

## 🚀 ฟีเจอร์หลัก
- **Real-Time Weather & Air Quality:** ดึงข้อมูลสภาพอากาศและ PM2.5 ในพื้นที่ปลูกทุเรียนจันทบุรี
- **Interactive GIS Map:** แสดงรายละเอียดสถิติและข้อมูลเฉพาะพื้นที่ปลูก
- **MixLab Chemical Compatibility:** ตรวจสอบความเข้ากันได้ของการผสมสารเคมีเกษตร
- **Cost & Profit Simulator:** คำนวณประมาณการกำไรสุทธิต่อพื้นที่ปลูก

## 🛠️ เทคโนโลยีที่ใช้
- HTML5 / CSS3 (Tailwind CSS)
- JavaScript (Vanilla JS ES6)
- Chart.js (Visualizations)
- Lucide Icons
- Open-Meteo Weather API
